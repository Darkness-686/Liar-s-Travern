# Liar-s-Travern
《骗子酒馆》规则

一句话概括：轮流出牌吹牛，质疑失败者和吹牛吹炸者对自己开一枪，比谁活到最后。

一、人数与牌组

· 4 人局，没有真人就自动部署AI，房主可选AI强度。
· 牌组：A、K、Q 各 6 张，王 2 张，共 20 张。
· 每人开局发 5 张手牌。
· 王是万能牌，可当作本轮牌面。

二、每轮开始

1. 洗牌，所有存活玩家各发 5 张。
2. 随机指定本轮牌面：A / K / Q 之一。
3. 第一轮随机先手；之后由上一轮受罚者先出。若受罚者已淘汰，则由其下家先出。

三、出牌与质疑

· 轮到你时，必须打出 1～3 牌，自动声明：“这些是 X（牌面）。”
· X 必须是本轮牌面。你可以说真话，也可以撒谎。
· 出牌数量公开，牌隐藏。
· 下一位玩家可以选择：
  1. 跟牌：继续打出 1～3 张，并声明同样是 X。
  2. 质疑：点质疑，翻开上一位刚打出的所有牌。
· 只能质疑上一位玩家，不能质疑更早的牌。
· 若轮到你时无牌可出，可以质疑上一位也可以选择跳过。
· 若其他人牌全部出完，你还没有出完，你必须质疑

四、质疑结算

· 翻开上一位刚打出的牌：
  1.若全部是本轮点数，或包含王：上一位说真话，质疑者输。
  2.若出现任何一张不是本轮点数、也不是王的牌：上一位撒谎，出牌者输。
· 输的人接受俄罗斯轮盘。
· 质疑过后重新洗牌发牌，进入下一轮

五、俄罗斯轮盘

· 左轮有 5-8 个弹巢（房主可设定），装 1 颗实弹。
· 输者拿枪对自己扣扳机。
· 空枪：存活。弹巢推进一格，下一次受罚者继续用同一把枪，中弹概率递增。
· 中弹：该玩家淘汰。

六、胜利条件

· 最后存活者获胜。

细节提醒

· 王在翻开时永远算真牌。
· 出牌必须声明“全是本轮点数”，不能只声明其中一张。
· 质疑是唯一翻开牌的方式。
· 每轮重新发牌，不是补牌。
